 UrbanPulse AI

UrbanPulse AI is a smart city infrastructure monitoring and emergency response platform built using Streamlit, Plotly, and PyDeck. The platform uses AI-driven analytics, geospatial heatmaps, predictive insights, and SOS emergency simulations to monitor urban congestion, traffic stress, weather impact, and critical city infrastructure in real time.

 Features

* AI-powered urban stress analysis
* Real-time geospatial heatmaps
* Predictive analytics dashboard
* Emergency SOS simulation system
* Smart traffic and infrastructure monitoring

 Tech Stack

Python • Streamlit • Plotly • PyDeck • Pandas • NumPy
